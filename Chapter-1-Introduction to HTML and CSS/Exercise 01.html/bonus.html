HTML & CSS Quick-Refrence Guide

A beginner-friendly Guide to essential tags and properties

What is HTML?

HTML (HyperText Markup language) is used to structure content on the web.It uses "tags" to define elements like headings, paragraphs, links, and more.

Common HTML Tags

1. Heading Tag

Used for defining headdings from largest(<h1>) to smallest (<h6>).

<h1>This is a heading</h1>

2. Paragraph Tag

This tag defines a paragraph

<p>This is a paragrapgh</p>

3. Anchor Tag

This tag is used to create hyperlink.

<a href="https://example.com">Visit</a>

4. Image Tag

This tag displays a image.

<img src="image.jpg" alt="Description">

5. Unordered Lists

This tag creates a lists with bullet points.


            <ul>
            <li>Cats</li>
            <li>Dogs</li>
            </ul>

6.Ordered Lists

This tag creates a lists with numbers.

<ol>
            <li>Sara</li>
            <li>Ahmed</li>
            </ol>

7.Bold Text

This tag makes the text bold

<b>Bold text</b>

8.Italic Text

This tag makes the text italic.

<i>Italic text</i>

9. Break Tag

This tag is to create a break in the line of text

line 1<br>Line 2

10.Form tag

This tag is used to create a form for user input


            <form>
          <label for=>"123"Email </label>
          <input id="123" type="text" placeholder="Email">
          </form>

What is CSS?

CSS (Cascading Style Sheets) is used to style Html content. It controls layout, color, font, spacing and much more.

Common CSS Properties

1. Color

p {color: #5c2a47; }

2. Background Color

body {background-color:rgb(252, 255, 223)}

3. Font Family

body {font-family: "Times new Roman",serif;}

4.Font Size

p {font-size: 1em; }

5. Text Align

h1 {text-align:left; }

6. Border

h1 {
                border: 2px solid rgb(0, 0, 0);
                padding:5px;

7. Margin

h1 {margin: 25px; }

8. Padding

div {padding: 3x 3px;}
